关于这个站点

这是第一篇文章，纯占位，用来验证 build.py 和 update.py 跑不跑得通。你随时可以删掉它。

写作流程

  1. 在 markdown_source/ 里写一个 .md
  2. 跑 python build.py
  3. 把生成的 html 手动归类到 work/、essays/ 或 fiction/
  4. 跑 python update.py 刷新四个索引页

索引页本身是静态 HTML，所以搜索引擎和分享预览都能正常抓到内容，不依赖浏览器跑脚本。

能用的语法

加粗、斜体、删除线、行内代码，还有一个链接。

print("代码块")
脚本干什么
build.pymarkdown 转 html
update.py刷新四个索引页

删除文章就是删掉那个 html，再跑一次 update.py。
